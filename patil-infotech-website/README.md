# Patil Infotech Website

A responsive static website for Patil Infotech and Management Research Centre, Kudus.

## Files
- `index.html` — website content and page structure
- `style.css` — responsive layout and visual design
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/favicon.svg` — browser tab icon

## Publish with GitHub Pages
1. Create a GitHub repository (Public is the simplest setup for GitHub Free).
2. Upload all files and the `assets` folder to the repository root. Keep `index.html` at the root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for the Pages URL to appear.
